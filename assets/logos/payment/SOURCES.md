# Logos moyens de paiement — provenance

Marks d'acceptation affichés dans le sélecteur (`PaymentBrandMarks`).

| Fichier | Source | Licence (code SVG) |
|---------|--------|--------------------|
| `visa.svg`, `mastercard.svg`, `paypal.svg` | aaronfagan/svg-credit-card-payment-icons (`flat-rounded`) | MIT |
| `apple-pay.svg`, `google-pay.svg` | simple-icons (`applepay`, `googlepay`) | CC0-1.0 |

Les **marques** (Visa, Mastercard, PayPal, Apple Pay, Google Pay) appartiennent à leurs détenteurs respectifs ; usage fonctionnel d'acceptation de paiement.

Pour une conformité stricte aux chartes (notamment Apple Pay / Google Pay), remplacer par les marks officiels téléchargés depuis les brand resources de chaque marque.
