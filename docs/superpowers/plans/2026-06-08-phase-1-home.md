# Phase 1 — Home (carte additive) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Supprimer le switch de rôle de la Home et le remplacer par une carte additive : l'expéditeur voit les trajets, le voyageur voit en plus les colis, pilotés par un filtre de focus local — sans aucune régression.

**Architecture :** Le rendu Home ne dépend plus de `ActiveRoleCubit` mais de la capacité `user.isTraveler` (via `AuthBloc`) plus un état local `HomeMapFocus` (Tout / Colis / Trajets, défaut Tout, voyageur uniquement). Une fonction pure `homeMapVisibility()` décide quels jeux de markers afficher — c'est le cœur testable. `_MapSenderView` (dans `home_screen.dart`) reste un `StatefulWidget` setState (legacy existant) ; on n'introduit pas de nouveau BLoC Home.

**Tech Stack :** Flutter, flutter_bloc (AuthBloc, AnnouncementBloc, PackageRequestSearchBloc, BidBloc), GoogleMaps (`AnnouncementMapView`), GetIt, flutter_test.

**Référence spec :** `docs/superpowers/specs/2026-06-08-phase-1-home-design.md`
**Fondation :** `docs/superpowers/specs/2026-06-08-navigation-additive-model-foundation.md`

**Stratégie de test (réaliste) :** `home_screen.dart` embarque un `GoogleMap` (platform view) → non testable en widget test classique. On concentre donc le TDD sur (1) la fonction pure `homeMapVisibility()` et (2) le widget isolé `HomeFocusFilter`. Le reste (`_MapSenderView`) est couvert par ces unités + une checklist de QA manuelle à la fin. C'est le compromis honnête : on ne fabrique pas de faux tests autour d'un platform view.

**Garantie zéro-régression (mapping) :**
- Pur expéditeur (`isTraveler == false`) → strictement inchangé (toujours trajets + filtres expéditeur, jamais de filtre de focus).
- Voyageur, focus **Colis** → identique à l'actuelle vue voyageur (markers colis, filtres colis, near-me colis, faire une offre).
- Voyageur, focus **Tout / Trajets** → NOUVEAU, additif (il voit aussi les trajets). Rien d'existant n'est retiré.

// lib/features/home/presentation/home_map_focus.dart

/// Ce que l'utilisateur veut voir sur la carte Home.
/// Visible uniquement pour les voyageurs ; défaut = [all].
enum HomeMapFocus { all, parcels, trips }

/// Décision pure : quels jeux de markers afficher sur la carte Home.
class HomeMapVisibility {
  const HomeMapVisibility({required this.showTrips, required this.showParcels});
  final bool showTrips;
  final bool showParcels;
}

/// Un pur expéditeur ne voit JAMAIS les colis. Un voyageur voit selon le focus.
HomeMapVisibility homeMapVisibility({
  required bool isTraveler,
  required HomeMapFocus focus,
}) {
  if (!isTraveler) {
    return const HomeMapVisibility(showTrips: true, showParcels: false);
  }
  switch (focus) {
    case HomeMapFocus.all:
      return const HomeMapVisibility(showTrips: true, showParcels: true);
    case HomeMapFocus.parcels:
      return const HomeMapVisibility(showTrips: false, showParcels: true);
    case HomeMapFocus.trips:
      return const HomeMapVisibility(showTrips: true, showParcels: false);
  }
}
```

// lib/features/home/presentation/widgets/home_focus_filter.dart
import 'package:dony/features/home/presentation/home_map_focus.dart';
import 'package:flutter/material.dart';
import 'package:google_fonts/google_fonts.dart';

/// Filtre d'affichage de la carte Home (voyageur uniquement). Défaut = Tout.
/// Ce n'est PAS un switch de rôle : c'est un filtre de contenu local.
class HomeFocusFilter extends StatelessWidget {
  const HomeFocusFilter({
    super.key,
    required this.focus,
    required this.onChanged,
  });

  final HomeMapFocus focus;
  final ValueChanged<HomeMapFocus> onChanged;

  @override
  Widget build(BuildContext context) {
    final cs = Theme.of(context).colorScheme;
    return Container(
      padding: const EdgeInsets.all(4),
      decoration: BoxDecoration(
        color: cs.surface,
        borderRadius: BorderRadius.circular(14),
        boxShadow: [
          BoxShadow(
            color: Colors.black.withValues(alpha: 0.10),
            blurRadius: 8,
            offset: const Offset(0, 2),
          ),
        ],
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          _Segment(
            label: 'Tout',
            isActive: focus == HomeMapFocus.all,
            onTap: () => onChanged(HomeMapFocus.all),
          ),
          _Segment(
            label: 'Colis',
            emoji: '📦',
            isActive: focus == HomeMapFocus.parcels,
            onTap: () => onChanged(HomeMapFocus.parcels),
          ),
          _Segment(
            label: 'Trajets',
            emoji: '✈️',
            isActive: focus == HomeMapFocus.trips,
            onTap: () => onChanged(HomeMapFocus.trips),
          ),
        ],
      ),
    );
  }
}

class _Segment extends StatelessWidget {
  const _Segment({
    required this.label,
    required this.isActive,
    required this.onTap,
    this.emoji,
  });

  final String label;
  final String? emoji;
  final bool isActive;
  final VoidCallback onTap;

  @override
  Widget build(BuildContext context) {
    final cs = Theme.of(context).colorScheme;
    return GestureDetector(
      onTap: onTap,
      child: AnimatedContainer(
        duration: const Duration(milliseconds: 200),
        curve: Curves.easeOutCubic,
        padding: const EdgeInsets.symmetric(horizontal: 12, vertical: 8),
        decoration: BoxDecoration(
          color: isActive ? cs.primary : Colors.transparent,
          borderRadius: BorderRadius.circular(11),
        ),
        child: Text(
          emoji == null ? label : '$emoji $label',
          style: GoogleFonts.plusJakartaSans(
            fontSize: 13,
            fontWeight: FontWeight.w700,
            color: isActive ? cs.onPrimary : cs.onSurfaceVariant,
          ),
        ),
      ),
    );
  }
}
```
